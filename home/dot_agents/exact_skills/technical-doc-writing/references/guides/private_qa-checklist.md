# 交付质检

按任务范围执行：大纲只查结构与内容，成稿兼查表达和交付。

## 内容与事实

- [ ] 主要读者、阅读任务、核心建议明确。
- [ ] 各主要章节有读者用途和主导语篇关系。
- [ ] 用户指定原句、数字、范围和修改已进入终稿。
- [ ] 事实、判断、假设、拟议方案、愿景、未知项可区分。
- [ ] 待验证边界未写成事实。
- [ ] 未虚构证据、负责人、日期、测试结果或技术细节。
- [ ] 删除实现细节仍保留目标、理由、方案机制；隐藏卫星后主线清楚。

## 提炼与表达

- [ ] 每段功能明确，每句有新信息，每个抽象词有具体所指。
- [ ] 共同前提、资源、边界不跨模块重复。
- [ ] 连续否定、空对仗、机械连接词未代替实际说明。
- [ ] 标题表达判断或读者问题，非容器标题。
- [ ] 句间关系真实；并列、因果、条件、对比、顺序不互相冒充。
- [ ] 总结只收束已有内容，不重复或新增结论。
- [ ] 未指定篇幅时，正文不超过 2000 字、一级章节不超过 4 个、开头摘要不超过 150 字；未通过附录转移字数。

## 图示与证据

- [ ] 架构、流程、状态、关系、界面在图更清晰时已实际配图，图后无重复文字。
- [ ] 图中对象、关系来自已知事实；图片、图题、正文术语一致。
- [ ] 用图源、占位符或表格代替实际图片时，已标为未完成。
- [ ] 核心图已按最终显示尺寸打开实际图片，检查文字、节点、连线、箭头、边界；问题已修订、再渲染并复查；未做视觉检查已明确标注。
- [ ] 未参与绘图的独立读者代理已据图片复述核心架构图主链路、关键关系，并用原事实核对；未完成已标注，未冒充真实读者测试。

## 真人范文校准

- [ ] 真人范文匹配交付类型、参照单元；用户未另附时已实际选择并阅读内置范文，未再次索要。
- [ ] 样段校准使用实际范文摘录，非“自然一点”等抽象要求。
- [ ] 独立校准编辑已返回完整校准稿并复核终稿。
- [ ] 措辞、详略、句间衔接的实际修改可回指范文。
- [ ] 未带入范文事实、作者口癖或翻译腔。
- [ ] 实际改写、复核未完成，或两轮后仍不满足时，已明确告知未完成校准。

## 目标读者代理测试

- [ ] 未参与写作和校准的独立 Agent 仅据候选终稿执行指定阅读任务。
- [ ] 读者代理已复述核心建议、依据、代价或未知项、下一步，并引用原文给出“能／有困难／不能”。
- [ ] 影响决策或操作的问题已修复并复核；两轮后仍有阻碍已说明未通过。
- [ ] 结果只称“目标读者代理测试”，未冒充真实读者测试。

## 最终判断

初次阅读者无需理解生成过程，即可说明“为什么做、做什么、凭什么、代价是什么、下一步是什么”。独立 Agent 校准和目标读者代理测试均非真实读者测试；无自然人实际阅读反馈，不得声称通过真人测试。
