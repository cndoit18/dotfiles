# 交付质检

按当前任务范围执行；大纲只检查结构与内容，成稿同时检查表达和交付。

## 内容与事实

- [ ] 主要读者、阅读任务和核心建议可辨认。
- [ ] 每个主要章节都有读者用途和主导语篇关系。
- [ ] 用户指定原句、数字、范围和修改进入最终版本。
- [ ] 事实、判断、假设、拟议方案、愿景和未知项可区分。
- [ ] 待验证边界没有被写成已成立事实。
- [ ] 没有虚构证据、负责人、日期、测试结果或技术细节。
- [ ] 删除具体实现后，目标、理由和方案机制仍完整；隐藏卫星后主线仍清楚。

## 提炼与表达

- [ ] 每段有明确功能，每句提供新信息，每个抽象词有具体所指。
- [ ] 共同前提、资源和边界没有在各模块重复。
- [ ] 不存在用连续否定、空对仗或机械连接词代替实际说明。
- [ ] 标题表达判断或读者问题，不是容器标题。
- [ ] 句间关系真实；并列、因果、条件、对比、顺序没有互相冒充。
- [ ] 总结只收束已有内容，不重复铺陈或新增结论。
- [ ] 用户未指定篇幅时，正文不超过 2000 字、最多 4 个一级章节且开头摘要不超过 150 字；未通过附录转移字数。

## 图示与证据

- [ ] 能用图清晰表达的架构、流程、状态、关系和界面已实际配图，图后无重复文字。
- [ ] 图中对象和关系来自已知事实，图片、图题和正文术语一致。
- [ ] 图源、占位符或表格替代图的情况已标为未完成。
- [ ] 核心图已按最终显示尺寸打开实际图片，检查文字、节点、连线、箭头和边界；发现的问题已修订、再渲染并复查，未执行视觉检查时明确标注。
- [ ] 核心架构图已由未参与绘图的独立读者代理依据图片复述主链路和关键关系，并用原事实核对；未完成时明确标注，代理测试未冒充真实读者测试。

## 真人范文校准

- [ ] 选择了与当前交付类型和参照单元匹配的真人范文；用户未另附范文时，已实际选择并阅读内置范文，而不是再次索要。
- [ ] 样段校准使用了实际范文摘录，而非“自然一点”等抽象要求。
- [ ] 独立校准编辑返回了完整校准稿并复核最终稿。
- [ ] 措辞、详略和句间衔接的实际修改可回指范文。
- [ ] 未带入范文事实、作者口癖或翻译腔。
- [ ] 未完成实际改写、复核或两轮后仍不满足时，已明确告知未完成校准。

## 目标读者代理测试

- [ ] 未参与写作和校准的独立 Agent 仅依据候选终稿执行了指定阅读任务。
- [ ] 读者代理实际复述了核心建议、依据、代价或未知项和下一步，并引用原文给出“能／有困难／不能”的结论。
- [ ] 影响决策或操作的问题已修复并复核；两轮后仍有阻碍时已明确说明未通过。
- [ ] 结果只称“目标读者代理测试”，没有冒充真实读者测试。

## 最终判断

初次阅读者无需理解生成过程，即可说明“为什么做、做什么、凭什么、代价是什么、下一步是什么”。独立 Agent 校准和目标读者代理测试都不等于真实读者测试；没有自然人实际阅读并反馈时，不得声称已通过真人测试。
