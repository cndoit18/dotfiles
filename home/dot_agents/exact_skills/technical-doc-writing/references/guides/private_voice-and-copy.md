# 语言与提炼

## 先判断语境

**技术方案 / 评审稿**：有判断、讲机制、写清代价与行动；不需要假装闲聊，也不靠术语制造权威感。

**个人风格文本**：保留作者真实的口语、犹豫、幽默和中英混用，但这些元素必须来自作者或范文，不能由模型伪造。

共同标准：像一个理解此事的人，把重要判断直接说清楚。不要默认用连续否定、空对仗、反问或机械转折制造“深度”。

## 从材料到可复述的判断

1. 找出作者希望读者相信、理解或决定什么。
2. 划出支持判断的事实、场景、因果和限制。
3. 标题优先表达本节结论或读者问题，少用“相关说明”“其他事项”等容器标题。
4. 每段只承担一个主要功能；背景、主张、证据和行动混在一段时，先拆分层级，再润色句子。
5. 删除同义复述，让下一段接住尚未回答的问题。

## 详略与句间衔接

- 顺序由读者任务和真实关系决定，不由“首先、其次、再次、最后”决定。
- 连接词只在关系真实存在且删去后会误读时保留；不用连接词掩盖逻辑断点。
- 长短句和段落详略随内容变化，不为“节奏感”刻意轮流使用某种句式。
- 读者已掌握的背景不重复；理解主线必需的背景就地补足。
- 每句提供新信息，每个抽象词有具体所指。
- 总结只收束已有内容，不重复整章，也不引入新结论。
- 不靠口语、口头禅或空泛的“像人”要求去 AI 味；需要通过真人范文校准时，必须发生实际改写，详见校准工作流。

## 接收反馈

用户给出一句更好的表达时，分析它增加了怎样的发现、场景、因果或边界，再把这种判断用于后文。不要把句子的表面结构无限复制。

用户指出机械转折或生造词时，不仅替换当前词，还要检查：指称是否明确、句间关系是否真实、是否存在没有信息量的抽象名词，以及同类问题是否在其他段落重复出现。
